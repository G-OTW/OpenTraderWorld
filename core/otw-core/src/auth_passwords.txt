# One lowercase candidate per line; `#` comments and blank lines are ignored. Matching is
# case-insensitive and ignores a trailing run of digits and punctuation, so `Password123!`
# is caught by the `password` entry. Keep entries lowercase and unsuffixed.
#
# This is the shipped floor, not a ceiling: it holds the passwords that dominate every
# public breach corpus, which is what makes an online guessing attack cheap. To use a
# bigger corpus, replace this file with a larger one (e.g. the first 100k lines of
# SecLists' rockyou-75.txt, lowercased and deduplicated) and rebuild. The file is embedded
# at compile time, so nothing is fetched at runtime and an air-gapped install behaves the
# same.
