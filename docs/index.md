## Beyond the docs

These pages cover installing, configuring and using your own instance. The project website,
**[opentraderworld.com](https://opentraderworld.com)**, is where everything around it lives:

- **[Live demo](https://demo.opentraderworld.com)**: click through a seeded instance, no account, no install ([how demo mode works](/guide/demo)).
- **[Tools](https://opentraderworld.com/tools)**: the 25+ modules by domain, in plain language.
- **[Community Docs](https://opentraderworld.com/docs)**: trading guides written by users, synced into every install.
- **[Suggestions & polls](https://opentraderworld.com/suggestions)**: propose a feature, vote on what ships next.
