# 设置参考

模块切换器中**设置**入口下的所有内容，按分区逐一说明。

## 账户

更改你的用户名或密码。保存更改需要当前密码，更改密码会**让所有会话退出登录**。

新密码至少 12 个字符，如果出现在公开的泄露名单中则会被拒绝。参见[密码规则](/zh/config/security#password)。

## 安全

双因素认证、当前登录你账户的浏览器，以及单个请求最长可运行多久。详见[账户安全](/zh/config/security)。

## 默认设置

- **语言**：立即应用于整个应用（en、fr、de、es、it、pt、zh）。
- **默认货币**和**时区**：模块为新条目和显示使用的初始值。

## 外观

应用的**强调色**，用于主按钮、激活状态、链接和图表高亮。可选择预设色块或取色器中的任意颜色；它会实时应用于整个应用，并对所有会话保存。*重置*会恢复为主题默认值。

## 网络 {#network}

谁可以访问应用：localhost、局域网、局域网 + HTTPS，或公网。详见[网络与远程访问](/zh/config/network)。

## 保险库 {#vault}

集中存放应用代你使用的 API 密钥和机密，而不必把同一个密钥粘贴到每个需要它的模块中。

一个**保险库**代表一个外部服务（例如 *Binance*），并保存命名的**密钥**：`apikey`、`secretkey` 等。你可以按需创建任意数量的保险库和密钥；之后各模块在任何需要机密的地方（服务商connector、订阅源凭据等）通过共用的选择器**按引用接入密钥**。

- **只写的值。**机密在保存时被密封，之后再也无法查看，只能替换或删除。密钥*名称*仍然可见。所有内容都使用应用的主密钥静态加密。
- **删除前先解除接入。**如果保险库或密钥仍接入某个模块，则禁止删除；请先在那里移除引用。每个保险库都会显示有多少连接在使用它。
- **请求跟踪**是可选的，且**按保险库而非按密钥**：同一保险库的所有密钥计入同一个计数器。限额仅供参考（只观察和显示）；绝不会限流。它为与 [API 速率](#api-rate)相同的视图提供数据。

新闻源机密也接受内联的 <code v-pre>{{vault.item}}</code> 占位符，由调度器在轮询时解析。参见[新闻](/zh/modules/news-research#news)。

## 模块

安装和卸载模块。所有模块都随应用一起提供：安装只是让模块在切换器和dashboard中可用，不会下载任何内容。卸载会隐藏它并使其无法访问；勾选*同时删除数据*则一并清除其存储的数据（永久）。

## 管理数据

按模块显示存储用量（表、行、大小）以及数据库总量，并提供**清除**操作，用于永久删除某个模块的数据（输入其名称确认）。清除无法撤销。

## 版本管理 {#versioning}

两个开关：**编辑器文件**和**策略**，各自显示已存储的版本数量及大小。开启时会警告每个版本都是完整副本，数据库会随之增长（图片和视频绝不会被复制）。关闭时会询问是保留这些版本（隐藏，直到你重新开启）还是全部删除。某个区域开启后，可从其历史菜单中按文件或按策略开启版本管理：参见[编辑器](/zh/modules/productivity#editor)和[backtest](/zh/modules/market-data#strategies-and-custom-indicators)。

## 备份与恢复

两个标签页，每个都有**备份**和**恢复**两侧：

- **完整**：针对你的部署、可直接复制的 `pg_dump` 和 `psql` 命令，包括加密变体，以及运行了自动备份的实例上自动备份的状态。
- **部分**：选择你想要的模块，下载为一个 zip，并在此处或另一个实例上加载该 zip。两侧都会先统计：你要取走的内容（按模块和按表），以及你要加载的文件所含内容与此处已有内容的对比。

参见[备份与恢复](/zh/guide/backup-restore)。

## 更新应用

显示当前版本，检查 GitHub 上是否有更新的版本，并列出需要在主机上运行的更新命令。参见[更新](/zh/guide/updating)。

## 日志

应用自己的日志存储，可按消息/目标搜索。**捕获级别**设定写入存储的最低严重程度（立即生效）。级别越低，捕获的细节越多，占用空间也越大。你可以在此处清除已存储的日志。

## API 速率 {#api-rate}

对外部数据服务商（行情数据、汇率、报价、订阅源）的出站调用dashboard，按 UTC 日统计：各服务商的请求数、错误、限流响应、已知的公布限额，以及最近限流命中的列表。它的存在是为了让你看到离服务商免费额度的上限有多近。

**此页面绝不会限流**：它只观察。唯一真正执行限额的地方是[connector自身的请求限额](/zh/config/connectors#request-limits)，作用于图表的按需获取；其他地方的限额只用于提示和警告，说“不”的仍然是服务商。

## data connector

Historical Data、Visualization、Watchlists 和 Trading Journal 共用的行情数据服务商账户列表：凭据、请求限额，以及每个connector可被哪些模块使用。详见[data connector](/zh/config/connectors)。同一界面也可在 **/connectors** 单独打开，也可从每个数据模块内的connector按钮进入。

## broker {#brokers}

Trading Journal、Portfolios、Visualization 和 Tax Calculator 共用的**只读broker账户**列表：凭据、各broker的设置，以及每个账户可被哪些模块使用。详见[broker账户](/zh/config/brokers)。这里的任何内容都无法下单、修改或撤销订单。

## 通知 {#notifications}

**通知渠道**的共用列表：应用被允许向哪里push，只需创建一次，供每个发出通知的模块复用。

渠道是**你自己拥有**的目的地。每个渠道保存一个机密，可在此处输入或从[保险库](#vault)接入，保存时密封，之后不再显示。

| 渠道 | 你需要提供 | 机密 | 其他字段 |
|---|---|---|---|
| **邮件** | 你自己的 SMTP 服务器 | 密码 | 主机、端口（587 STARTTLS、465 TLS）、发件人、收件人、用户名 |
| **Telegram** | 一个 BotFather 机器人 | 机器人token | 聊天 ID |
| **Slack** | 一个传入 Webhook | Webhook URL | 无 |
| **Discord** | 一个频道 Webhook | Webhook URL | 无 |

这四种对主机而言都是免费的：账户由你提供，应用无需你注册任何东西。部分**非机密**字段也可以接入保险库条目，例如 Telegram 的**聊天 ID**，这样配置渠道时无需把该 ID 以明文放在配置里。

可被授予渠道的模块：

| 模块 | push内容 |
|---|---|
| **RemindMe** | 已触发的提醒 |
| **Watchlists** | 价格警报 |
| **Mailbox** | 需要处理的邮件账户 |
| **Webhook** | 被重定向到某个模块的入站载荷 |
| **Historical Data** | 长时间暂停，以及一批下载的结束 |
| **Visualization** | 已触发的图表警报 |
| **Trading Journal** | 新交易的行情数据补全 |
| **backtest** | 模拟交易的成交，或其汇总摘要 |
| **Portfolio Tracker** | 可提前授予；目前不push任何内容 |
| **Automator** | `notify` 块发送的任何内容 |

- **按模块授权。**每个渠道都指明允许向它发送的模块，或*全部*。检查在服务端执行：从未被授予某个渠道的模块无法访问它，其机密甚至不会为该模块解密。
- **每个渠道一个开关。**停用渠道会让它在所有地方静默，而不会删除它或其凭据。
- 在依赖某个渠道之前先**测试发送**。

同一界面也可从每个发出通知的模块内部打开，因此无需离开当前页面就能即时添加渠道。它被有意排除在 [MCP](#mcp) 目录之外：任何agent都无法创建渠道或扩大授权。

## MCP {#mcp}

让 AI agent通过受控网关使用应用。详见 [AI agent（MCP）](/zh/config/ai-agents)。

## 外部控制 {#external-control}

通过聊天渠道（Telegram、Slack、Discord）操控应用。详见[外部控制（聊天）](/zh/config/external-control)。

## 语音 {#voice}

按键说话命令和听写：语音引擎、两个快捷键以及你的语音命令。详见[语音控制](/zh/config/voice)。麦克风仅在 HTTPS 或 localhost 下可用。
