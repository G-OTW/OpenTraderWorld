# 投资组合与财富

相互独立的模块，用于跟踪你关注什么、持有什么、花费多少，以及税单可能是多少。

## Watchlists {#watchlists}

你想要留意的品种的命名清单：没有持仓，没有账本，只有报价。

- 通过搜索**添加品种**（加密货币来自 CoinGecko，股票/ETF 来自 Yahoo），从**精选模板**（Crypto Top 10、Magnificent 7、US Index ETFs、Semiconductors）开始，或**导入 Portfolio Tracker 的投资组合**，重新导入时会对账而不是重复添加。
- 每行显示实时美元价格、**24 小时 / 3 天 / 7 天 / 30 天涨跌**、**30 天迷你走势图**、交易所，以及每个品种的自由格式**备注**。可按任意列排序，按名称过滤。
- 每个清单可**自动刷新**，从每分钟到每天（默认 15 分钟）。页面会估算请求速率，并在**某个间隔有触发免费 API 限流的风险之前发出警告**。报价在服务端缓存，所以重新打开页面是即时的，也不会访问服务商。

### 自定义报价来源

公共来源（CoinGecko / Yahoo）无需任何设置即可使用。如果你有自己的行情数据账户，可以接入一个 **[data connector](/zh/config/connectors)**，也就是 [Historical Data](/zh/modules/market-data#histdata) 和图表所用的同一个共用服务商账户，只需创建一次并授权给 Watchlists。每个 connector 都带有自己的凭据（直接输入，或从[保险库](/zh/config/settings#vault)中选取）和自己的请求限额。

- 清单可以**固定一个 connector 作为其默认来源**，每个品种也可以覆盖它：*跟随清单*、*自动*，或指定的 connector。
- 每个品种的**服务商代码**（`BTCUSDT`、`AAPL.US`…）会自动推导，当服务商对某个品种的命名不同时仍可编辑。
- 失败的报价会显示在**它自己的那一行**，所以一个坏品种不会遮住清单的其余部分。

::: warning 了解你套餐的限制
由自定义来源支持的清单会解锁 **5 秒–30 秒的刷新间隔**。这个速度足以迅速耗尽 API 套餐：超出的调用会失败，并可能导致你的密钥被封。请关注**设置 → API 速率**中的计数器。
:::

### 价格警报

任何品种都可以带有警报，从其行上的铃铛设置。每个警报读起来就是一句你从左到右组装的话，*当 BTC 相对现在波动 ±5% 时通知我*：

- **价位**（价格高于或低于某个值），或以 **%** 或 **$** 衡量的**波动**，向上、向下或任一方向。
- 波动从**现在**起衡量，或在**滚动窗口**（1h、4h、12h、1d、3d、7d、30d）内衡量。
- **单次或重复**，并带有重新武装延迟（5 分钟到 1 天），这样单次摆动不会在每次刷新时都触发。
- **目的地**：应用内收件箱，加上你为每个警报选择的任意[通知渠道](/zh/config/settings#notifications)。Watchlists 只能指向已授予它的渠道。

警报在**刷新循环内的服务端**求值，所以页面关闭、浏览器关闭时它们仍会触发。

### 清单描述

自选清单的名称下带有可编辑的描述，用来说明这个清单实际是做什么的。

## Portfolio Tracker {#portfolios}

你实际持仓的实时市值，每个账户或主题一个投资组合。

- 通过搜索**添加资产**（加密货币或股票/ETF）并记录**买入/卖出操作**（日期、数量、价格、手续费、备注）。已实现和未实现盈亏、平均成本和权重都根据账本计算。
- **每个资产的交易货币**：每个资产声明其操作所用的货币，所以以欧元买入的股票不会被当作美元记录。表单标签随该货币而变。现货报价保持以美元计：成本基础和已实现盈亏按**每笔操作自己的日期**使用 [Trading Journal](/zh/modules/journal) 的汇率换算，所以三年前的买入保留其历史汇率。表单中的弹出框解释每个价格的来源。
- **自动刷新**：一次性的对账步骤会按价格来源检查每个持仓；修复任何显示为*未解析*的（或标记为手动），并启用**每日自动更新**，此后价格会每天在后台刷新。
- 每个投资组合：市值、成本基础、未实现/已实现/总盈亏、最佳和最差资产、按资产或类别的**配置**，以及随着刷新累积而逐渐充实的**市值随时间变化图**（日/周/月/年）。
- **描述**在创建后仍可编辑，旁边是随投资组合保存的可折叠**投资论点**备注，说明你为什么持有所持有的东西。

### 现金、收入和成本

账本不只有买入和卖出。操作标签页中的**现金与收入**可以登记**存入**、**取出**、**股息**、**利息**、**票息**、**手续费**或
**税**，每项使用自己的货币，并可选择扣除手续费。收入可以指明支付它的
持仓，如果来自账户本身则不指明。

根据这些行，投资组合得到按货币的现金余额、总收入和真实的
净资产（持仓加现金）。负现金会如实显示，绝不会被钳制为零：它意味着保证金，或者
账本缺少存入记录，两者都值得一看。

### 分析

**Analysis** 标签页在一个地方回答绩效、风险和敞口。七个独立的
视图，每个只请求自己需要的数据，所以 *Book* 在全新安装上即时渲染，
而 *Stress* 需要 K 线。

无法回答的视图会**说明原因以及该怎么做**。它绝不会显示一个未经测量的零。
尚无历史、账本太短无法年化、未选择基准、基准没有 K 线、未设定目标：每一种都是一句话加一个按钮，而不是空图表。

| 视图 | 需要 | 回答 |
|---|---|---|
| **Book** | 账本，别无其他 | 净资产、投入与现金、未实现、已实现、收入、按类别的配置 |
| **Performance** | 每日历史 | 每个窗口的收益、IRR、年化、净投入 |
| **Risk** | 每日历史 | 波动率、回撤、Sharpe、Sortino、Calmar、最佳和最差时期 |
| **Benchmark** | 每日历史和基准的 K 线 | 指数在你的波动率下本应获得的收益、alpha、beta、捕获率 |
| **Income & costs** | 账本的现金行 | 已收到的收入、已支付的成本、年度拖累、不含费用的曲线 |
| **Allocation** | 目标配置 | 当前与目标的对比、偏离、使其回归的交易 |
| **Stress** | 每个持仓的日线 K 线 | 历史重放和因子冲击，以及覆盖的比例 |

每个视图都使用同一个窗口选择器：1M、3M、6M、YTD、1Y、3Y、5Y、全部，或自定义
范围。比你的历史更长的窗口会被报告为**未覆盖**，并给出它
实际拥有的天数，而不是冒充完整的三年。

### 绩效和风险

**Performance** 报告时间加权收益以及 IRR，它们回答不同的
问题。时间加权反映的是投资本身的表现，已对存入调整，因为投入
不是上涨。IRR 是**你**得到的，按资金加权，所以买入时机选得好只会在
那里体现。净投入就放在它们旁边，不足两个月的收益
不会年化：把六周的收益乘以八是预测，而不是衡量。

**Risk** 读取同一条曲线：波动率、最大回撤、Sharpe、Sortino、Calmar、收涨
天数的比例、最佳和最差的日、月、季度和年，以及每一次超过
2% 的回撤及其**用了多久才填平**。仍未结束的会标记为进行中，并显示你
低于上一个高点多远、已经持续了多少天。

年化系数是**根据你自己的曲线测得的**，而不是假定的。股票账本
每年大约交易 252 天，加密货币账本交易 365 天，而混合的两者都不是。Sharpe 和
Sortino 使用测量设置中设定的无风险利率。

### Benchmark

选择一个你有其日线 K 线的品种（SPY、QQQ、BTCUSDT），页面会回答
唯一能平息争论的问题：**该指数在你的波动率下本应获得的收益**，与你
实际赚到的并排显示。承担三倍风险而跑赢指数，不算真正跑赢。

下面是：两者的总收益和年化收益、波动率、最大回撤和 Sharpe 并排显示，
然后是 alpha、beta、跟踪误差、信息比率以及上行和下行捕获率。

你的账本按**基准自己的交易日**衡量。把 24/7 的投资组合与
指数逐日比较，指数的每个周一都会吞掉你的一个周末，这会悄悄
低估你的收益。

### 收入和成本

你收到了什么，付出了什么，以及支付所花费的代价。一侧是股息、利息和
票息；另一侧是交易手续费和账户费用，年度拖累以占你平均净资产的
比例表示。

曲线绘制两次：真实发生的，以及去掉手续费部分的同一个账本。手续费
已经包含在你的成本基础和现金中，所以这是一次比较，而不是你
自己能做的减法。

### 目标配置

在**设置目标**中说明每个桶应持有净资产的多少份额，以及它偏离多少才算
失衡。配置必须合计 100%，可以一键把剩余部分分给某个桶。保存空列表会关闭该视图。

随后视图按桶显示当前与目标、偏离、各自是否在其区间内，以及**能填平差距的交易**：买入这么多这个，卖出这么多那个。任何你持有但没有目标的，都会被列出而不是被忽略。

仅供显示。这里不会下任何订单，也不会自行再平衡。

### 压力测试

两种引擎，两者都会告诉你该数字覆盖了你账本的多少。

**历史重放**把 2008、2020、2022、2018 Q4 或 2021 年加密货币顶部的已实现每日路径应用到你今天的持仓，使用这些日期内各品种自己的 K 线。没有模型，没有代理。当时不存在的品种没有路径：它会被**点名并排除**，绝不会用指数替代。

**因子冲击**移动一个真实的品种（标普 500、纳斯达克、利率、EUR/USD、石油、信用利差），并通过**测得的**敏感度到达每个持仓，该敏感度由其自己的 K 线拟合。没有 K 线、历史太短或拟合没有解释力的持仓
得不到 **beta**：它连同其权重进入*无法解释*，标题会写成
“在可测量的账本 74% 部分中为 −11.8%”。现金的 beta 为零，这通常是
已有的唯一分散化。

以基点计的利率冲击通过写在情景上的久期到达债券，所以这个
数字是可以商榷的。衰退、通胀飙升和信用利差扩大以这些部分的可编辑
组合形式提供。

就绪面板会在你运行任何东西之前列出哪些可以压力测试、哪些不能，所以
薄弱的结果会事先得到解释，而不是事后。

### 每日历史

除 *Book* 之外，以上每项指标都需要一条曲线，而快照只从你开启每日任务
那天开始。否则一个你保留了六年的投资组合会被从
上周二开始衡量。所以曲线是根据账本和已存储的 K 线**逐日重建**的。

Analysis 标签页中的齿轮会打开**测量设置**：

1. **为每个资产指定 K 线代码**以及这些 K 线的计价货币。账本中的代码
   不一定是你的服务商提供的代码，而以欧元买入、却用美元 K 线定价的股票，
   会偏离汇率。
2. **下载缺失的 K 线**。它们会作为普通的 [Historical Data](/zh/modules/market-data#histdata)
   任务，通过授予投资组合的 connector 排队。如果没有任何一个带有你的某个品种，
   它会被点名，并说明该授予什么。
3. **重建曲线**。它会报告重建的天数，以及因某个持仓
   当天没有 K 线而跳过的天数。无法估值的日子不会被存储，而不是错误地存储。

编辑过去日期的操作会把曲线标记为**自该日期起过期**并予以说明。
重建仍由你决定。刷新投资组合也会下载缺失的内容并延长其后的曲线，
并在 broker 无法提供你的某个品种时告诉你。

### 导入操作账本

投资组合标题栏中的**导入**读取 broker 导出文件、电子表格或其他跟踪器（CSV、TSV、JSON、Parquet），并把每一行变成一笔买入或卖出操作。检测引擎与 [journal 导入](/zh/modules/journal#import-a-trade-book)相同：六种语言的表头加上值嗅探，每列单独判定分隔符、小数和日期约定，无法识别的列保持未映射。

它拒绝猜测三件事：

- **品种是什么。**文件中的每个品种都必须指向一个资产：你在此投资组合中已持有的（自动匹配）、要创建的新资产，或*跳过*。未解析的品种会阻止导入，资产只有在你确认后才会创建。
- **既不是买入、也不是卖出、也不是它能识别的类型的行**会被列为行错误，而不是被虚构成一笔操作。股息、存入、取出、手续费和税**是**能识别的，支持六种语言，并按其自身类型登记。如果文件根本没有声明类型，请为整个导入设置一次默认值。
- **缺失的价格**由金额 ÷ 数量推导并标记，绝不会悄悄填充。

在你验证预览之前不会写入任何内容。每次导入是一个**批次**，可整体还原（已创建的资产保留），并且**按投资组合**去重，所以重新导入同一个文件不会有任何变化。

### 从 broker 导入持仓

投资组合标题栏中的 **From a broker** 读取 [broker 账户](/zh/config/brokers)的资产负债表而不是文件：与你账本的差异逐行显示，你接受的每一行都会写入使投资组合一致的那一笔操作。broker 发布成本基础的地方使用它（Interactive Brokers），没有发布的地方则询问你（加密货币交易所只发布数量，别无其他）。

## MyWealth {#wealth}

**所有内容**的净资产：证券账户、房产、加密货币、现金、贵重物品。Portfolio Tracker 跟踪实时定价的持仓，而 MyWealth 跟踪你自己估值的任何资产。

- 添加带名称、类型、货币和分类的资产，然后随时间**记录价值更新**（价格 × 数量，或直接的价值，附带备注）。历史可编辑。
- 按月或按年的**净资产图**，外加按分类的明细。多币种，汇率处理与 journal 相同（没有汇率的资产会被排除并标记）。
- **模板**，与 journal 的类似：保留的价格/数量字段决定价值，自定义字段保存每次修订的备注。
- **拥有或欠下**：资产可以是**负债**（抵押贷款、借款），所以标题数字是真实的净资产。页面在轧差之前会显示你拥有什么、欠下什么。
- **关联投资组合**而不是复制它：关联的投资组合每次都从跟踪器实时读取，所以它在你净资产中的价值绝不会是过期的副本。
- **估值时效**：告诉资产应该多久重新估值一次，页面会点名已超期的资产，最旧的在前。三年前估值的房子会无声地出错，而这正是打破沉默的东西。关联的投资组合永远不会过期：它是被读取的，而不是被记住的。

## Managers' Portfolios {#mportfolios}

浏览**超级投资者的 13F 投资组合**：著名基金经理持有什么、仓位大小、近期活动、申报市值与当前市值、52 周区间。可按基金经理或按代码过滤（*谁持有 AAPL？*）。

由于 13F 数据按季度变化，你可以为任何投资组合**保存快照**并随时间对比。

## Tax Calculator {#taxcalc}

对交易与投资税务的粗略估算。**不构成税务建议。**

- **配置档案**从**国家模板**（个人或专业）开始，并保持完全可编辑：边际所得税率、社保费用、资本利得和股息免税额、可选的**财富税档位**（例如 CH、ES、NO）、长期减免档位。
- 以**摘要**模式（期初/期末价值、投入、取出、已实现份额）或**明细**模式（资本利得、衍生品收益、加密货币收益、股息、利息、结转的以前亏损）输入数字。
- **加载 Trading Journal**：安装了 journal 后，一键加载某个税务年度的已实现盈亏，拆分为资本/衍生品/加密货币收益，按年末汇率换算。
- **From a broker**：当有 [broker 账户](/zh/config/brokers)授予 Tax Calculator 时，直接从账户读取税务年度，折叠为已平仓头寸并按表单行汇总，每笔处置按其自身退出日期的汇率换算。
- 结果显示估算税额，附带每项明细（应税额、免税额、税基、税率）和实际税率。把情景保存到历史记录以便对比。

## Subscriptions {#subscriptions}

把每一项周期性成本（交易工具、数据源、流媒体）放在一个列表中，包含价格、货币、计费频率（每周/每月/每季度/每年）和分类。

你会得到每月/每年的**支出图表**（分组或按订阅），每个订阅的**月度等值**、下次扣费日期，以及下个月的合计。暂停订阅可以让它留在列表中但不计入。
