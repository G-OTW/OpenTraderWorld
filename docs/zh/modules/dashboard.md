# Dashboard 与导航

应用的主屏幕，以及位于每个模块之上的两样东西：搜索框和通知收件箱。

## Dashboard 页面

Dashboard 自带五个预设页面，每种工作方式一个：**Investor**（长期持仓）、**Trader**（执行与交易时段）、**Quant**（研究、backtest 和算法工作）、**Portfolio**（持仓）和 **Utilities**（自动化、笔记和工具）。每个页面都带有一组现成的小组件。它们只在首次使用时创建，之后就是普通页面：可以随意重新排列。只有你自己的页面可以删除。

你也可以在侧边栏的**工作区**分区中用 **Custom +** 创建**自己的页面**，该分区列出你的所有 dashboard。每个页面有名称、可选的描述，以及显示在收藏栏中的简短**标记**。顶部的**收藏栏**容纳一到五个页面，用旁边的星标添加或移除；第一个条目就是 dashboard 打开时显示的页面。收藏栏已满时，新的星标会询问要替换哪一个收藏。

可以按交易日的划分来使用它们：*早晨*页面放新闻源、经济日历和例程检查清单；*持仓*页面放投资组合和自选清单；*事务*页面放待办和计时器。

## 编辑布局

**自定义**会进入**编辑布局**模式。页面是 12 列的自由网格：磁贴从左到右排列，一行放不下时换到下一行，不存储任何行。在编辑模式下你可以：

- 用**添加**磁贴加入**模块磁贴**（指向模块的链接，同一个模块可出现在任意多个页面上）或**小组件**；页眉中的**添加小组件**在编辑模式之外也可使用；
- 把磁贴拖到任意位置：其后的磁贴随之移动，网格重新排列；按列跨度**调整**任意磁贴的大小；
- 设置一行的高度（**紧凑**、**标准**或**高**），并打开小组件的**配置**（磁贴上的齿轮），其中**标题**高度会把小组件变成通栏的标题带，用作 Free text 分区标题；
- 插入**间隔**：一个高度可调的通栏空白。

磁贴是链接，而不是副本：从页面中移除一个磁贴绝不会影响模块或其数据。

## 小组件

小组件是模块的实时交互预览：它通过该模块自己的 API 读写，所以你在小组件中做的操作是真实的。对应模块未安装的小组件不会被提供。

大多数小组件有多个**变体**，每个变体是同一数据的不同视图：例如 Net worth 提供当前值、变化、趋势、资产与负债、按类别拆分、待复核资产和最大资产。**添加小组件**把每个变体列为单独的卡片，之后可在小组件配置中的 **Widget type** 切换。下表列出每个小组件在其所有变体中涵盖的内容。

| 小组件 | 作用 |
|---|---|
| **Free text** | 你自己写的笔记或标题，轻量 markdown。 |
| **Notes** | 最近编辑的 Editor 文档、文档数量，以及一行即可创建笔记的输入框。 |
| **News feed** | 来自所选订阅源的最新条目，列表或网格形式。 |
| **Mailbox** | 最新的未读邮件，最新的在前。 |
| **Time tracker** | 无需离开页面即可开始/停止项目计时器。 |
| **Quick trade** | 选择一个分类 + 模板并打开添加交易表单。 |
| **Journal analytics** | 净 PnL、胜率、盈亏比、权益曲线、未平仓头寸、敞口、行为洞察和每日 PnL 热力图。 |
| **Goals** | 带进度的简短目标列表；可内联添加。 |
| **ToDo** | 未完成的任务，可就地勾选。 |
| **Trading routine** | 今天的检查清单，可就地勾选。 |
| **Mindset** | 当天的打卡。 |
| **Reminder** | 快速添加提醒的表单。 |
| **Reminder stats** | 未读通知、即将到期和逾期的提醒，以及触发最多的提醒。 |
| **Calendar** | 今天和本周一览。 |
| **Economic calendar** | 即将到来的宏观事件，精简显示。 |
| **Portfolio** | 带实时市值的投资组合摘要。 |
| **Subscriptions** | 每月周期性支出，以及接下来续费的内容。 |
| **Net worth** | 当前净资产、你设定窗口内的变化，以及迷你走势图。 |
| **Watchlist** | 所选清单的实时报价：价格、24 小时和 7 天涨跌。 |
| **Fundamentals** | 宏观序列和看板、公司快照、按季度、年度或 TTM 的报表行、可排序的公司、过滤后的申报文件、即将发布的财报，以及相对已存储同行的估值。读取已存储的数据，不消耗服务商额度。 |
| **Automator** | 正在运行的工作流、下一次计划运行、各工作流成功率、最近的失败和收藏的快速运行。 |
| **Webhooks** | 收到的事件、最近事件、各端点错误率，以及已沉默的端点。 |
| **Historical data** | 已存储的数据集、存储大小、下载队列、覆盖缺口、数据新鲜度和失败的下载。 |
| **Backtest** | 最佳已保存运行、排行榜、策略库和收藏的快速运行。 |
| **Finance database** | 按分类和文件夹的收藏、目录更新状态和过期收藏。 |
| **Charts** | 已保存的布局和列表、活跃的图表警报和最近的警报活动。 |
| **Managers' portfolios** | 跟踪的基金经理、规模最大的持仓组合、持仓漂移和按变动排序的主要持仓。 |
| **Community Docs** | 按类别的已保存参考资料、最近添加和快速访问。 |
| **Quant tools** | 可用的数据集和 backtest、单一资产的风险和回撤、相关性、季节性、相对其历史区间的已实现波动率，以及估计的市场状态。 |
| **Tax calculator** | 本年度估算税额、实际税率和逐年对比表。 |
| **Prompt store** | 按标签列出你的提示词，点击一个即可复制。 |
| **Resources** | 所选分类中的书签。 |
| **Agent** | 向助手提问：选择模型和工具，发送，进入对话。 |
| **Agent activity** | 最近的对话和 token 用量。 |

Fundamentals 和 Quant 小组件在页面可见时每五分钟刷新一次。刷新期间它们会保留之前的结果，并在更新失败时给出说明。Fundamentals 只读取已存储的快照；请在相应的模块页面中加载或更新缺失的数据。

在**小组件设置**中，选择一个 Quant 数据集，或由二至二十个兼容数据集组成的篮子。篮子成员必须共享时间框架；日内成员还必须共享服务商。风险提供 90%、95% 或 99% 的历史 VaR 置信度，季节性提供收益、波动率、成交量或 K 线区间，波动率和状态卡片则提供其窗口或状态数量。每项分析都会显示其实际历史长度和样本量。

Fundamentals 设置允许你选择并排序宏观看板的序列，挑选最多四个公司指标或表格列，选择同行公司，并将申报文件和财报过滤为关注的公司。报表 TTM 对连续四个季度求和，适用于利润表和现金流量表的行；资产负债表的值仍是期末观测值。同比对比要求上一年有相同的财年期间，且对比基数为正。

悬停、聚焦或轻点热力图单元格可查看其值及样本数。缺失的单元格以斜线填充，与实测的零值区分。窄卡片显示每月季节性摘要或最强的两两相关性。小组件链接会打开相关的模块标签页，并带上所选的序列、数据集或篮子。

在宽度不超过 767px 的屏幕上，dashboard 卡片堆叠为单列，编辑模式下用**上移** / **下移**按钮代替拖动。已保存的排列在更宽的屏幕上依然可用。

## 全局搜索

顶栏中的搜索框，在任何地方都可以用 <kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd> 聚焦，在你没有输入字段时也可以直接按 <kbd>/</kbd>。

默认情况下它匹配**模块名称**、**设置分区**和 **Resources** 条目。框旁边的**图层开关**会把范围扩大到你的内容：Editor 页面、Goals、Calendar 事件、ToDo、Routines、Reminders、Prompts、邮件主题、Community Docs，以及 Fundamentals 的公司、序列和文档。

有两件事它是刻意不做的：它只匹配**标题和名称，绝不匹配正文**，并且只搜索你已安装的模块。结果按类型分组返回，前缀匹配的在前；用 <kbd>↑</kbd>/<kbd>↓</kbd> 和 <kbd>Enter</kbd> 导航。

## 通知

顶栏中的铃铛带有未读计数，并会打开**通知收件箱**，[RemindMe](/zh/modules/productivity#remindme) 的提醒触发时会落在这里，其他模块的通知也会进来：Automator 工作流、入站 [webhook](/zh/modules/productivity#webhooks)、邮箱轮询、数据下载和券商同步等后台任务，以及安全事件，例如从本账户从未用过的地址登录。你在应用中时触发的通知，还会以横幅形式滑入。

发送到**邮件、Telegram、Slack 或 Discord** 的投递通过设置中共用的[通知渠道](/zh/config/settings#notifications)进行，你也在那里决定哪些模块可以向每个渠道 push。收件箱本身始终开启，无需设置。
