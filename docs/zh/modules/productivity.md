# 笔记与组织

日常使用的模块：文档、任务、目标、日历、提醒，以及几个为交易者的纪律而设计的模块。

## Editor {#editor}

Notion 风格的富文本文档编辑器。文档保存在文件夹树中；输入 `/` 打开块菜单。

- **块**：标题、列表、待办列表、引用、代码块、分隔线、链接、图片（上传或通过 URL）、文字颜色、高亮、字号、常规或全宽。自动保存。
- **数据库**：一种带类型化列（文本、选择、URL…）的文档类型，可按**表格**、**看板**（按选择列分组）或**画廊**（带封面图片列）查看。拖动可重新排序行和列。
- **提交发布**：将文档发送到 [Community Docs](/zh/modules/news-research#community-docs) 审核队列，保留格式，并附带语言、分类和可选的作者署名。
- **版本**（可选启用）：在[设置 → 版本管理](/zh/config/settings#versioning)中开启版本管理，然后从某个页面或数据库的历史菜单中按页面开启。**保存版本**会存储带日期和可选备注的快照；打开其中一个可只读查看，恢复它（恢复后的状态会保存为一个新版本，备注为被恢复版本的日期）或删除它。历史记录在一个窗口中打开，可搜索备注和日期；与当前文件匹配的版本会被标记。备注上限 500 个字符。图片和视频不会被复制：版本指向相同的上传内容。为某个文件关闭版本管理时，会询问是保留还是删除其版本。删除文件时，其版本也会在确认后一并删除。拥有 Editor 写入权限的 agent 可以通过 [MCP](/zh/config/ai-agents) 保存、恢复和删除版本。

## ToDo {#todos}

一个不碍事的任务列表：任务带截止日期、时间、分类和备注。可按待办/已完成/已逾期过滤，按截止日期排序；逾期/今天/即将到期的标记会负责提醒你。dashboard 小组件会显示未完成的内容。

## Goals {#goals}

带有**可衡量指标**的目标。为每个目标设定截止日期、分类，以及一个或多个带当前值、目标值和点数的指标。随着进展递增它们，目标的完成度随点数而变。可按进行中/已达成/已逾期过滤；拖动可排序。

## Calendar {#calendar}

个人日历（年/月/周/日），用于带分类、颜色、地点和备注的事件。它的特色是**叠加层**：它还可以显示你的 **Reminders**、**带截止日期的 ToDo** 和 **Goal 截止日期**，每一项都可以切换：在一个地方看完这一周。创建事件时还可以同时创建一个在开始时间触发的同步提醒。

## RemindMe {#remindme}

提醒，一次性或周期性的（带开始日期、结束日期或最大次数），以**应用内通知**形式触发，并配有通知收件箱。

- **关联提醒**：把提醒附加到另一个模块中的条目上（目标、订阅的扣费、journal 复盘…），它会深度链接回该条目。大多数模块都有一个*添加提醒*按钮来预填这些内容。
- **渠道**：也可以投递到**邮件、Telegram、Slack 或 Discord**，从共用的[通知渠道](/zh/config/settings#notifications)中选择。提醒会列出 RemindMe 已被授予的渠道；凭据和授权位于设置中，整个应用只需配置一次。

## Webhooks {#webhooks}

给任何外部服务一个私有 URL，用来**向 OpenTraderWorld POST 警报**：图表和警报平台、broker 通知、在线监控、脚本，任何能发出 HTTP 请求的东西。负载会被接收并路由到某个模块。

- **私有 URL，无需请求头**：每个端点在 URL 路径中带有一个 **256 位 token**（`/api/hooks/<token>`），因为许多警报发送方无法设置 `Authorization` 请求头。token 以**哈希**形式存储，创建时只显示**一次**；失败的查找会被限速。
- **宽松的负载**：发送纯文本或 JSON；解析器接受宽松的字段名，所以大多数发送方无需特殊格式即可工作。
- **路由**：每个端点把其负载重定向到一个目标模块。v1 的目标是 **[RemindMe](#remindme)**：传入的负载会成为应用内通知，并继续 push 到你已启用的渠道（邮件/Telegram/Slack/Discord）。
- **投递日志**：保留每个端点最近的投递记录，让你可以确认发送方确实联系到了你，并查看它发送了什么。

在 **/webhooks** 管理端点。

::: warning 发送方必须能够连到你
只有发送服务能打开到你主机的连接，webhook 才有用。在 `local`（以及纯 LAN）网络模式下，外部什么都连不上，当当前模式无法从互联网访问时，页面会向你警告。要么在[设置 → 网络](/zh/config/network)中更改模式，要么把隧道（例如 Cloudflare Tunnel）指向主机，同时保持应用其余部分私有。
:::

## Trading Routines {#routines}

在你选择的工作日到期的周期性**交易时段检查清单**：盘前准备、盘中纪律、盘后复盘。按天勾选条目，浏览过去的日子，并查看**14 天一致性条**，了解你是否真的坚持了自己的流程。已包含初始检查清单。

## Time Tracker {#time}

带开始/停止**计时器**（或手动添加的时间段）的项目，可选的**时间预算**及超预算警告、计划结束日期，以及用于为时间估值的**时薪**。**明细**标签页按天/周/月绘制已跟踪的小时数，可按项目和分类过滤。如果计时器在应用关闭时仍在运行，它会询问是保留还是还原这段时间。

## Mindset {#mindset}

针对交易者心理的每日**打卡**。在交易时段之前或之后回答几个提示：量表（专注、纪律）、选项（平静 / 焦虑 / FOMO）、自由文本。提示**完全可自定义**；已包含初始集合。**趋势**视图会绘制你最近几次打卡的答案，历史记录让你重新阅读任何一天。

## Prompt Store {#prompt-store}

用于存放你反复使用的 **AI 提示词**的库：市场回顾、journal 提问、研究模板。提示词以缩略卡片网格显示（名称、标签、最后保存时间），可搜索名称、标签和正文。

- **标签**：在编辑器中添加自由格式的标签；用标签栏过滤网格。
- **评分与过滤**：给提示词点赞或点踩，并快速过滤到任一类。
- **版本历史**：每次保存都会保留；打开提示词的**历史**可预览任何更早的修订并**回滚**到它（恢复会保存为新版本，所以不会丢失任何东西）。
- **复制**：派生一个提示词以创建变体。
