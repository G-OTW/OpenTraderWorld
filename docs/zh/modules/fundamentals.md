# Fundamentals

在一个地方阅读经济和公司，数据来自发布这些数字的来源：带图表的宏观序列、公司财报、SEC 申报文件、财报电话会议记录、ETF 持仓、市场日历和另类数据。一切都存放在你自己的数据库中，所以图表、[Agent](/zh/modules/agent) 和其他模块读取它时无需再次询问服务商。

Fundamentals 没有自己的服务商设置。每个来源都是授权给该模块的 **[data connector](/zh/config/connectors)**：页面标题栏中的插头图标会打开共用的 connector 界面。许多来源是**无需密钥**的公共机构（SEC EDGAR、美国财政部、欧洲央行、Eurostat、BIS、OECD、IMF、世界银行、CFTC、FINRA、USAspending）；其余的需要你自带免费或付费的密钥。在你添加 connector 并授权给 Fundamentals 之前，不会获取任何内容。

## 页面

| 页面 | 显示内容 |
|---|---|
| **Macro** | 按分类（增长、通胀、劳动力、利率、货币、调查、住房、能源、财政、持仓）列出你的序列，一张图上最多四个，美国国债收益率曲线和央行政策利率。 |
| **Company** | 概况和关键指标、财务报表、预期、财报、分部、股息和回购、所有权、同行、ESG 和薪酬、申报文件和电话会议记录。 |
| **ETF** | 概况、前几大持仓、行业和国家敞口。 |
| **Events** | 即将发布的财报、IPO、公司行动和央行决议。 |
| **Documents** | 所有已存储的申报文件和电话会议记录，带全文搜索和记录阅读器。 |
| **Alternative data** | 国会议员交易、游说支出、联邦合同和已授予的专利。 |
| **Library** | 用于你保留的序列和公司（可过滤）、来源优先级，以及哪个服务商提供哪类数据的标签页。 |

**自定义**（右上角）按页面设置密度、显示哪些分区以及它们的顺序。

## 宏观序列 {#macro}

**添加序列**会搜索服务商的目录，或接受服务商自己的代码（FRED 上的 `CPIAUCSL`，欧洲央行上的 `HICP/M.U2.N.000000.4D0.ANR`）。代码在存储任何内容之前会先向服务商核对：未知的代码是一个指明它的错误，绝不会是空序列。**添加入门集合**一键添加一组首批的美国和欧元区序列。

| 服务商 | 密钥 | 覆盖内容 |
|---|---|---|
| FRED | 免费 | 大多数美国序列（也镜像 BLS、BEA 和 Census） |
| US Treasury | 无 | 每日面值收益率曲线、公共债务总额 |
| ECB, Eurostat | 无 | 欧元区通胀、利率、货币、GDP、失业率 |
| BIS | 无 | 央行政策利率、有效汇率 |
| OECD, IMF, World Bank | 无 | 领先指标、世界经济展望、各国年度数据 |
| BLS, BEA, EIA, US Census | 免费 | FRED 滞后或缺少某个序列时的美国详细数据 |
| CFTC | 无 | 持仓报告（Commitments of Traders），非商业净持仓 |

一行是一个**期间**：观测值按其所覆盖期间的起始日存储。图表在读取时计算变换（水平值、同比、期间变化、差值、指数 100），所以不会存储任何派生数据。同比会把每个值与一年前同日期的值比较；缺失的期间显示为空缺，而不是与错误的月份比较。衰退阴影遵循 NBER 的日期。

## 公司 {#company}

Company、ETF 和 Alternative data 共用一个**品种选择器**：先是你的收藏，然后是最近打开的 15 个。其搜索涵盖每个已存储的品种，外加公司的 EDGAR 匹配项。

输入一个代码。它在 SEC EDGAR 的代码列表中解析；EDGAR 不认识的代码是一个错误，绝不会是最佳猜测。打开一家公司会存储它，并在后台获取：

- 来自 XBRL 公司事实的**财报**，年度和季度。第四季度和年初至今的现金流量行通过差值推导；每一行保留其被报告时所用的标签。
- **申报文件**（10-K、10-Q、8-K、委托书…），附带指向来源的链接。
- 从 Form 4 解析的**内部人交易**。

其他标签页读取你所连接的聚合器，最佳来源优先。如果某个服务商的套餐缺少某个数据集（例如免费的 FMP 密钥没有财报历史），则交给下一个，授权给该模块但缺少密钥的 connector 会被跳过。对于价格，历史最长的获胜（免费套餐通常只到一两年）：

| 数据 | 服务商 |
|---|---|
| 预期、目标价、评级动作 | Financial Modeling Prep, Alpha Vantage, Finnhub |
| 财报（EPS 预期和实际、下次日期） | Financial Modeling Prep, Alpha Vantage, Finnhub |
| 分部 | Financial Modeling Prep |
| 股息和拆股 | EODHD, Massive, Financial Modeling Prep, Alpha Vantage |
| 13F 持有人 | Financial Modeling Prep |
| 空头持仓 | FINRA, Massive |
| 同行 | Financial Modeling Prep, Finnhub |
| ESG 和高管薪酬 | Financial Modeling Prep, Finnhub |
| 电话会议记录 | Financial Modeling Prep, Alpha Vantage, Finnhub |
| 价格和市场比率 | 任何带有日线股票 K 线的行情数据 connector |

**Library → 来源优先级**列出每个有多个来源的数据集（包括电话会议记录），按尝试其服务商的顺序排列。在服务商旁边选择一个排名即可将其移到那里；**默认顺序**会恢复应用的顺序。价格没有顺序：历史最长的获胜。

每个标签页都会说明是哪个服务商应答以及何时应答，或者给出指明解决办法的错误（通常是要添加一个 connector，或者套餐不包含该数据集）。应答会被保留并复用，直到它过期（日历为几小时，预期为一天，持有人为一周）；**刷新**会立即重新询问。

打开页面不会消耗你在刚刚拒绝过的服务商上的额度：拒绝了数据集的服务商（套餐、品种、速率限制）会被搁置一段时间，从网络错误后的几分钟到套餐拒绝后的一周不等，在其 connector 上声明的额度已用完的服务商也是如此。标签页会说明这一点以及下一次自动尝试的时间；**刷新**会一次询问每个服务商。

**关注**一家公司可使其每天刷新，并在有新申报文件时通知你。

### 电话会议记录 {#transcripts}

Transcripts 标签页列出服务商为该公司持有的电话会议；记录的文本在你第一次打开时获取，按发言者轮次拆分，准备好的发言与问答分开，并可与其他文档一起搜索。

## 另类数据 {#alt}

公司就是在 Company 中打开的那家；在这里输入的代码会先被打开。

| 标签页 | 服务商 |
|---|---|
| 国会议员交易 | Quiver Quant（所有议员的最新交易，或某家公司的），Finnhub 高级版（按公司） |
| 游说 | LDA.gov, Quiver Quant |
| 政府合同 | USAspending, Quiver Quant |
| 专利 | USPTO Open Data Portal（免费密钥）, Quiver Quant |

公共来源通过**注册名称**而不是代码来识别公司。LDA.gov、USAspending 和 USPTO 使用 EDGAR 存储的名称查询，只有在去掉标点和法律后缀后名称相同，记录才算数（`Lockheed Martin Corp` 匹配 `LOCKHEED MARTIN CORPORATION`，绝不匹配 `Lockheed Martin Aculight`）。每个标签页都会显示它所匹配的名称。对于合同，使用母公司接收方，所以归在其名下的子公司计入，而单独注册的子公司（Amazon 名下的 Amazon Web Services）不计入。

LDA.gov 需要一个免费密钥（在 lda.gov 注册）。它的防火墙会拒绝美国以外的网络（HTTP 403 并指明原因）：请通过美国的连接访问，或使用 Quiver Quant。一份报告只计一次：修订版替换原件，不含支出的游说者登记则被排除。通过另一名称的子公司进行游说的公司（JPMorgan Chase 的 JPMorgan Chase Holdings）只显示以其自身名称提交的报告。

## 自动刷新与通知 {#refresh}

已存储的序列会在其频率表明可能有新值发布时刷新：日度序列每天两次，周度或月度序列每天一次，季度序列每三天一次，年度序列每周一次。被关注的公司每天从 EDGAR 刷新一次。没有授权 connector 的来源会被跳过。

出现新期间的序列和出现新申报文件的被关注公司（内部人表格除外）会触发通知，push 到授予 Fundamentals 的[渠道](/zh/config/settings#notifications)（页面标题栏中的铃铛）。

## Dashboard 小组件 {#dashboard}

[Dashboard](/zh/modules/dashboard) 提供宏观序列和看板、公司快照、报表历史、公司、申报文件、即将发布的财报和估值对比。卡片显示货币、报告基准和日期；它们的刷新只读取已存储的数据。即将发布的财报使用公司已存储的财报快照，或者在它没有未来日期时使用已存储的市场日历。估值使用手动选择的已存储公司，或其 Peers 标签页中已存储的同行。缺失的预期和比率仍然不可用，而不是被推断出来。

## 搜索与 agent {#search}

顶栏搜索在开启内容标题时，会查找已存储的公司、序列和文档标题。

一旦 token 被授予 **Fundamentals**，agent 就可以通过 [MCP gateway](/zh/config/ai-agents) 以只读方式访问已存储的内容：序列和观测值、公司、报表、申报文件、电话会议记录、内部人交易以及每个已存储的数据集。查询服务商、刷新和添加序列不在其内：它们会消耗你的服务商额度。
