# 新闻与研究

## News {#news}

自托管的新闻聚合器。创建 **dashboard**（例如 *Crypto*、*Macro*），为每个添加**来源**，让调度器在后台轮询它们。

### 来源

- **RSS / Atom**：粘贴订阅源 URL 即可。
- 没有 RSS 的内容使用 **API (JSON)**：设置端点、方法、请求头和查询参数，然后把 JSON 路径映射到条目字段（条目数组、标题、URL、日期、摘要、用于去重的唯一 id）。API 密钥放入每个订阅源的**机密**中，加密存储，并在请求头或参数中以 <code v-pre>{{secret:NAME}}</code> 引用，之后不再显示。

订阅源 URL、请求头或参数也可以带有指向共用[保险库](/zh/config/settings#vault)的 <code v-pre>{{vault.item}}</code> 占位符。调度器在轮询时解析它，所以一个密钥可以在多个订阅源和模块之间复用，而无需存储在订阅源配置中。

每个来源都有自己的**轮询间隔**；会检测重复的来源，因此同一个订阅源不会在多个 dashboard 间被重复获取。可按 dashboard 开始/停止轮询，或按需刷新某个来源。

### 阅读

按搜索、来源、类型和日期范围过滤条目；紧凑或完整视图；可选的 60 秒自动刷新，并带有“{n} 条更新，点击加载”横幅。News 小组件也可以放在你的 dashboard 主页上。

## Mailbox {#mailbox}

你的资讯简报、市场新闻邮件和 broker 邮件，从**你自己的邮箱**读取：没有任何内容经过第三方。

### 连接邮箱

选择你的服务商（Fastmail、Gmail、iCloud、Zoho、mailbox.org、Posteo、Migadu、Proton Bridge 或任何其他 IMAP 服务器），服务器设置会预先填好；你提供**应用专用密码**，它存放在共用的[保险库](/zh/config/settings#vault)中，别处不存放。

**Outlook.com / Microsoft 365** 的 IMAP 不再接受密码，所以改用 OAuth 登录：在 Microsoft 打开一个标签页，你批准访问，然后直接返回本应用（授权码 + PKCE，任何地方都不存储机密）。它需要你自己做一次性的免费应用注册：Entra ID → 应用注册 → 新注册，然后 身份验证 → *移动和桌面应用程序*，填入表单显示的重定向 URI（默认本地安装为 `http://localhost:5454/mailbox/oauth`），允许公共客户端流，再设置 API 权限 → 委托的 `IMAP.AccessAsUser.All`。将应用程序（客户端）ID 粘贴到表单中。由此产生的登录凭据在保险库中加密，并在每次获取时自动续期。

Microsoft 只接受 `https://…` 或 localhost 上的 `http://` 的重定向 URI，而且它的门户拒绝输入为 `127.0.0.1` 的 `http` URI，所以请在 `http://localhost:5454` 打开应用（匹配 localhost 重定向时会忽略端口），或在[设置 → 网络](/zh/config/settings#network)中把它放到 HTTPS 之后。如果你的是纯 HTTP 局域网地址，登录会回退到在 `microsoft.com/devicelogin` 输入代码；这对个人 Outlook.com 账号仍然有效，但 Microsoft 365 租户现在默认会阻止设备代码登录。

这种续期是关于维护唯一需要了解的事：Microsoft 会在**90 天未使用**后丢弃登录凭据，所以暂停了几个月的邮箱会要求重新连接。应用会在闲置 60 天后发出警告，如果登录被撤销（更改密码、重置 MFA、管理员策略），邮箱会显示**需要登录**以及一个重新连接按钮，而不是悄悄失败。

访问严格**只读**：文件夹以只读方式打开，绝不会在你的服务器上标记、移动或删除任何内容。如果你有多个邮箱，可以连接多个。

> 建议为资讯简报使用**专用地址**。这样你的个人邮件完全不会进入应用，应用专用密码可以一键撤销，而发件人泄露其名单的那一天，你也能确切知道是哪一个泄露的。

### 保留什么

邮件列表邮件（任何带有 `List-Unsubscribe`、`List-Id` 或 `Precedence: bulk` 的邮件）会被自动保留。其他一切只会*被记录为等待你决定的发件人*，在你归档之前不会存储任何内容。broker 的对账单就是这样进来的：对新发件人点一下，归档为 **Broker**。

发件人归入四个类别（**News**、**Newsletter**、**Broker**、**Other**），可随时切换，阅读界面为每个类别提供一键切换，当你有多个邮箱时还可按邮箱过滤。

### 阅读

邮件在到达时会被清理（移除脚本、样式、表单和框架），并在沙盒框架中显示。**远程图片保持阻止**，直到你要求加载，所以资讯简报中的追踪像素永远不会触发，发件人也无法得知你已打开。附件（broker 对账单、PDF）可从邮件中下载。

每封邮件：加星标、标记为未读、归档、**提醒我**（今晚 / 明天 / 本周末，直接进入 [RemindMe](/zh/modules/productivity#remindme)）和**退订**，发件人支持一键退订时会替你发送，否则在标签页中打开。

### 商店

**商店**标签页是你自己的资讯简报列表：每个刊物一张卡片，带名称、链接、简短描述和主题（心态、金融、交易、地缘政治、经济、其他），按领域分组，一键即可打开。它是独立的，即使没有连接任何邮箱也有用。

## Economic Calendar {#economics}

日历视图中即将到来的宏观事件（央行决议、CPI 公布、就业数据），让你知道交易时段之前有什么。点一下即可为某个事件添加提醒。

## FinanceDatabase {#findb}

一个可搜索的 **300,000+ 个品种**的目录：股票、ETF、基金、指数、货币和加密货币。

首次使用时你要**安装目录**（一次性下载约 15 MB，在后台导入）。之后它保存在本地，**搜索绝不会访问网络**。可按代码或名称搜索，按资产类型和属性过滤，并把品种加星标放入**收藏**，用文件夹和备注组织（例如一个 *Watchlist* 文件夹）。

目录有自己的发布周期，与应用分开：页眉会显示已安装的是哪个**快照**，**检查更新**按钮会询问发布方是否有更新的版本。更新会就地重新导入目录；你的收藏会保留，并重新关联到新的行。

该目录基于 Jeroen Bouma 的开源项目 [FinanceDatabase](https://github.com/JerBouma/FinanceDatabase) 构建，这是一个由社区维护的金融品种数据集。

## Resources {#resources}

用于交易书籍、文章、视频和工具的书签库：名称、可选链接、描述，按分类组织。刻意保持简单。

三种显示方式：**卡片**、**列表**，以及每个书签带缩略图的**画廊**。缩略图可以上传、以 URL 粘贴，或一键从链接自己的社交预览获取；没有缩略图的书签会得到一个首字母磁贴，而不是网格里的一个空洞。

## Community Docs {#community-docs}

由社区撰写的指南，从 [opentraderworld.com 上的库](https://opentraderworld.com/docs)同步，并可在应用内**离线阅读**。可按分类浏览、搜索并为收藏加星标。

文档以**卡片或列表**显示，由你选择，分类卡片会预览它包含的文档，让你在打开前就知道里面有什么。

你可以贡献：在 [Editor](/zh/modules/productivity#editor) 中撰写文档，然后使用**提交发布**。它会进入审核队列，批准后出现在所有人的库中。
