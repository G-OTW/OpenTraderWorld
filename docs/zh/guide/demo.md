# 演示模式

在 **[demo.opentraderworld.com](https://demo.opentraderworld.com)** 有一个公开的沙盒：真实的应用，预置了示例数据，由所有人共享，每 **15 分钟**重置一次。无需安装，无需注册；你会以 `demo` 身份直接登录。

本页说明该模式是什么，让你知道自己看到的是什么，也方便你想向别人展示应用时自己运行一个。

## 它是什么

演示模式是后端在以 `OTW_DEMO=1` 启动时采取的一种运行姿态。**它绝不会被隐式启用**：普通安装不会受到下面任何内容的影响。

- **数据库在每刻钟重置。**种子数据从模板恢复，所以你所做的任何更改都会在整点、:15、:30 或 :45 消失。应用内的横幅会倒计时到下一次重置。
- **自动以 `demo` 账号登录。**没有需要猜的密码，也不用创建账号。
- **所有人共用一个数据库。**其他访客的交易、笔记和对话你能看到，你的也会被他们看到。不要输入任何你不愿公开的内容。

## 被阻止的内容

闸门是**默认拒绝**的：请求必须匹配明确的允许列表，否则会以 `demo_disabled` 被拒绝。没人考虑过的路由是关闭的而不是开放的，这与 [MCP 目录](/zh/config/ai-agents)遵循的规则相同。

大致如下：

| 被阻止 | 只读 | 完全可用 |
|---|---|---|
| 设置、退出登录、账户与密码、网络、备份、更新、数据清除、模块安装/卸载、**保险库**、经纪商、模拟交易、外部控制、入站 Webhook（`/api/hooks`）、MCP 端点本身、通知渠道、FinanceDatabase 安装、服务商下载 | **Automator**、**Trading Bots**、Webhooks 模块、data connector、订阅源、文件、基金经理的投资组合、MCP 设置与token、API 速率、已存储的数据集、agent服务商、记忆与技能 | 日志、backtest、量化、投资组合、日历、待办、目标、编辑器与数据库、提示词、资源、订阅、税务计算器、时间、dashboard、搜索、agent聊天 |

所以你可以记录一笔交易、运行backtest并与助手对话；但不能更改网络模式、生成token、导出数据库，或让这台机器代你从计费的服务商处获取数据。

其中有三项值得说明：

- **保险库**被完全关闭。它是唯一一个整个用途就是保存凭据的存储，而这个数据库是共享且公开的。
- **Automator** 是只读的：可以浏览图、已保存的修订版本及其运行历史，但保存、测试、运行或定时调度workflow都会返回 `demo_disabled`。workflow能触及其token所授予的一切，并且可以调用任意 URL，而这正是公开沙盒不能提供的。
- **Trading Bots** 是只读的：演示模拟账户上有两个预置机器人，一个被其保护规则缩小了仓位，另一个被其保护规则暂停，用来展示机器人页面。两者都未启用（arm）也不会运行，创建、运行或启用机器人都会返回 `demo_disabled`。

聊天消息还限制为 2000 个字符。

## 每位访客的配额

开销大的端点要花真金白银，所以每个端点都带有**两**个预算：每位访客的份额，以及叠加其上的全局上限。仅按 IP 限制无法控制总支出；仅设全局限制则会让一个脚本化的访客把所有人锁在外面。

| | 每位访客 | 整个演示 | 时间窗口 |
|---|---|---|---|
| **agent运行** | 3 | 8 | 10 分钟 |
| **agent运行** | 10 | 40 | 24 小时 |
| **backtest与参数扫描** | 10 | 30 | 10 分钟 |
| **图表序列读取** | 120 | 600 | 10 分钟 |

助手运行在**固定使用免费模型的共享密钥**上，启动时确定；长期记忆和外部 MCP 服务器处于关闭状态。

## 运行你自己的演示

演示有自己的一套栈，位于 `deploy/demo/`，与普通安装相互独立：

```bash
cd deploy/demo
cp .env.example .env                              # throwaway values only
docker compose -f docker-compose.demo.yml up -d --build
./reset.sh --init                                 # build the seed template once, then reset
```

然后通过主机的 crontab 每 15 分钟重置一次，在每个整刻钟执行，以与应用显示的倒计时一致：

```
*/15 * * * * /path/to/deploy/demo/reset.sh
```

该栈以 `OTW_DEMO=1` 运行 core。`deploy/demo/.env` 中有两个可选密钥：`OTW_DEMO_LLM_KEY`，助手运行所用的共享 OpenRouter 密钥；以及 `OTW_DEMO_AV_KEY`，一个开启新闻情绪数据源的 Alpha Vantage 密钥（在构建种子时读取）。没有前者，助手无法回答；没有后者，该数据源保持关闭。

在该栈之外，相同的组成部分是：

```bash
OTW_DEMO=1        # in the core service's environment
otw-core --seed-demo   # once, against a scratch database
```

种子数据是公开的：随仓库发布，不含任何机密，并且如果已存在 `demo` 用户则直接跳过。重置是由主机驱动的 `CREATE DATABASE … TEMPLATE` 恢复，而不是由应用执行。

::: warning 不要把演示模式指向你的数据
种子会写入 `DATABASE_URL` 所指的任何数据库，而重置会覆盖它。请使用临时数据库。
:::
