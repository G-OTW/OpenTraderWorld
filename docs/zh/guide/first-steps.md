# 第一步

你已经[安装](/zh/guide/install)了 OpenTraderWorld，并拿到了管理员凭据。下面介绍如何把它调成你想要的样子。

## 登录

打开应用，在 `/login` 登录。如果你的密码是**由安装程序生成**的，首次登录时会要求你**选择新密码**，因为生成的密码只能使用一次。

你可以随时在**设置 → 账户**中更改用户名或密码。更改密码会使所有会话退出登录。被锁在外面了？没有重置邮件：请在主机 shell 中恢复，参见[忘记密码](/zh/guide/troubleshooting#forgot-password)。

接下来，在**设置 → 安全**中：开启**双因素认证**，并检查哪些浏览器处于登录状态。在让本机以外的任何设备访问应用之前，请先完成这一步。参见[账户安全](/zh/config/security)。

## 设置默认值

前往**设置 → 默认设置**并选择：

- **语言**：立即应用于整个应用（英语、法语、德语、西班牙语、意大利语、葡萄牙语、中文）。
- **默认货币**和**时区**：作为各模块的初始值。

## 安装模块

打开**设置 → 模块**。每个模块都随应用一起提供；安装模块只是让它出现在模块切换器和dashboard中，不会下载任何内容。

- **安装**你想要的模块。从少量开始，随时可以添加更多。
- 部分模块依赖其他模块：**Historical Data Visualization**、**backtest**和**Quant Tools**都需要**Historical Data**（它们处理其下载的数据集）。
- **卸载**会隐藏模块并使其无法访问；除非你同时勾选*删除数据*，否则其数据会保留。可随时重新安装。

不知道从哪里开始？请参阅[模块概览](/zh/modules/)了解每个模块的用途。

## 熟悉应用

- **模块切换器**（左上角）：在已安装的模块之间跳转。每个模块拥有自己完整的工作区：自己的侧边栏、页面和内容。
- **dashboard**（主页）：由模块的磁贴和小组件组成的面板，页数不限。参见[dashboard与导航](/zh/modules/dashboard)。
- **搜索**（顶栏，<kbd>⌘K</kbd> / <kbd>Ctrl+K</kbd>，或 <kbd>/</kbd>）：查找模块和设置分区；图层开关可将范围扩大到你自己的内容。
- **铃铛**（顶栏）：通知收件箱，提醒和 Webhook 警报会出现在这里。
- **设置**：账户、默认设置、外观、网络、模块、数据、备份、更新、日志、connector、保险库等。参见[设置参考](/zh/config/settings)。

## 建议的后续步骤

1. **尽早养成备份习惯**：参见[备份与恢复](/zh/guide/backup-restore)。
2. 如果其他设备需要访问应用，请在更改任何设置之前先阅读[网络与远程访问](/zh/config/network)，并首先开启[双因素认证](/zh/config/security#totp)。
3. 要使用外部行情数据服务商？按需在**设置 → data connector**中为每个账户创建一个**[data connector](/zh/config/connectors)**。没有connector应用也能正常工作，而且有几家服务商无需密钥。
