## 文档之外

这些页面涵盖自有实例的安装、配置和使用。项目网站 **[opentraderworld.com](https://opentraderworld.com)** 则提供其他所有内容：

- **[在线演示](https://demo.opentraderworld.com)**：点击浏览一个预置数据的实例，无需账号，无需安装（[演示模式的工作方式](/zh/guide/demo)）。
- **[工具](https://opentraderworld.com/tools)**：按领域浏览 25+ 个模块，用通俗的语言介绍。
- **[社区文档](https://opentraderworld.com/docs)**：由用户撰写的交易指南，同步到每一个安装实例中。
- **[建议与投票](https://opentraderworld.com/suggestions)**：提出功能建议，为下一个上线的功能投票。
