## Au-delà de la documentation

Ces pages couvrent l'installation, la configuration et l'utilisation de votre propre instance. Le site du projet,
**[opentraderworld.com](https://opentraderworld.com)**, rassemble tout ce qui l'entoure :

- **[Démo en ligne](https://demo.opentraderworld.com)** : parcourez une instance pré-remplie, sans compte ni installation ([fonctionnement du mode démo](/fr/guide/demo)).
- **[Outils](https://opentraderworld.com/tools)** : les plus de 25 modules par domaine, en langage clair.
- **[Docs de la communauté](https://opentraderworld.com/docs)** : des guides de trading écrits par les utilisateurs, synchronisés dans chaque installation.
- **[Suggestions et sondages](https://opentraderworld.com/suggestions)** : proposez une fonctionnalité, votez pour les prochaines.
